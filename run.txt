  PREREQUISITES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  2. Node.js 18+     → https://nodejs.org
  3. Git             → https://git-scm.com

  4. Docker Desktop  → https://docker.com
  5. PostgreSQL 15   → (or use default SQLite)
  6. Redis 7         → (or use in-memory fallback)

  QUICK START (LOCAL DEV — NO DOCKER)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Open TWO terminals:

  ┌─────────────────────────────────────────────────────┐
  │  TERMINAL 1: Backend (FastAPI + ML Pipeline)        │
  └─────────────────────────────────────────────────────┘

    cd backend
    pip install -e ".[dev]"
    uvicorn app.main:app --reload --port 8000

    → API docs:    http://localhost:8000/docs
    → Health:      http://localhost:8000/health
    → DB:          Auto-creates stocksense.db (SQLite)
    → Admin user:  admin@stocksense.local / admin

  ┌─────────────────────────────────────────────────────┐
  │  TERMINAL 2: Frontend (React + Vite)                │
  └─────────────────────────────────────────────────────┘

    cd frontend
    npm install
    npm run dev

    → Dashboard:   http://localhost:3000
    → Prediction:  http://localhost:3000/
    → Metrics:     http://localhost:3000/dashboard
    → Poison Log:  http://localhost:3000/poison
    → Admin:       http://localhost:3000/admin

  ┌─────────────────────────────────────────────────────┐
  │  HOW IT CONNECTS                                    │
  └─────────────────────────────────────────────────────┘

    Frontend :3000  ──/api/*──▶  Backend :8000  ──▶  ML Pipeline
                    ──/stream/*──▶  SSE events

    Vite proxy (vite.config.ts) forwards:
      /api/*     → http://localhost:8000/*  (REST)
      /stream/*  → http://localhost:8000/*  (SSE)

    If backend is down, frontend falls back to mock data automatically.

  PRODUCTION START (DOCKER)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    2. docker-compose up --build

    Services started:

  API ENDPOINTS (Backend :8000)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  GET  /health               → Health check
  POST /auth/login            → JWT login (form: username, password)
  GET  /predict?ticker=AAPL   → Next-day OHLCV prediction
  GET  /data/ohlcv?ticker=AAPL&days=90  → Historical candlestick data
  GET  /metrics               → PPL, MAE, AUC, cycle history, buffer status
  GET  /poison/log            → Paginated poison events
  POST /ingest/trigger        → Manual data ingest (admin)
  GET  /ingest/status         → Recent ingest jobs
  POST /admin/unlearn         → Trigger unlearn cycle (admin)
  POST /admin/rollback        → Rollback to prior cycle (admin)
  POST /admin/inject-poison   → Test poison detector (admin)
  GET  /stream/events         → SSE real-time pipeline events

  ML PIPELINE (Standalone)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  The ML pipeline can also run standalone without the backend:

    cd ml
    pip install torch transformers datasets accelerate yfinance pandas scipy scikit-learn

  Data ingestion:
    python -m stocksense.data.ingestion --ticker AAPL --period 2y

  Fine-tune on clean data:
    python -m stocksense.training.finetune --model_path ./models/Qwen1.5-0.5B --data_path ./data

  Run unlearning:
    python -m stocksense.training.run_unlearn --method ascent_plus_descent

  Evaluate:
    python -m stocksense.evaluation.run_eval --model_path ./output/stock/current

  Run MIA attack:
    python -m stocksense.evaluation.run_mia --model_path ./output/stock/current

  NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Frontend works standalone with mock data — no backend needed for UI preview
  • When backend is running, all hooks auto-switch to live API data
  • SSE events stream in real-time during ingest/unlearn cycles
  • Default admin credentials: admin@stocksense.local / admin
  • SQLite is default for dev; set DATABASE_URL for PostgreSQL
  • Redis is optional; in-memory fallback for SSE and job queue
